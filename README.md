# Costing Dashboard - Next.js

A full-stack logistics costing dashboard connected to AWS RDS PostgreSQL.

**Features:**
- Real-time data from RDS
- Works with any PostgreSQL database
- Deploy to Vercel (free)
- Share link with team instantly
- Auto-updates on git push

**Tech Stack:**
- Next.js (React framework)
- PostgreSQL (via `pg` driver)
- Vercel (hosting)
- Chart.js, XLSX (browser libraries)

See `DEPLOYMENT.md` for setup instructions.
